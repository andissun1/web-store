# Интернет-магазин

> Сервис онлайн-продаж с возможностью управления товарами и заказами.

## Функционал

- Авторизация и разделение доступа по ролям
- Поиск, сортировка, пагинация
- CRUD операции по товарам, заказам, комментариям
- Возможность добавлять товары в избранное и корзину за счёт памяти браузера
- Страница администратора для отслеживания заказов, кол-ва пользователей и товаров
  
Имеется адаптивная вёрстка под смарфоны, планшеты и компьютеры

## Как запустить проект
Проект уже запущен на Vercel, но при желании можно настроить локально запуск  

Понадобится docker-compose  
В корне проекта создаём .env файл:
```
PORT = 3005
CONNECTION_STRING=mongodb://admin:mongopass@myMongo:27017/testdb?authSource=admin
JWT_SECRET=test
MY_USERNAME=admin
MY_PASSWORD=mongopass
MY_DATABASE=testdb
```

Запускаем контейнеры:
```
docker compose up --build
```

Готово. Интернет магазин доступен локально - http://localhost 💪
